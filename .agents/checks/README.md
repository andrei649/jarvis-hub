# Repo-local review checklists

Load [functional change](functional-change.md) for any code change, then only the relevant [security and authority](security-authority.md) or [clients and platforms](clients-platforms.md) checklist. Read the subsystem's governing document in [the ownership map](../../docs/CODEBASE_OWNERSHIP.md). These are reviewer prompts, not a new approval gate or a substitute for executable tests, trusted policy, or [AGENTS.md](../../AGENTS.md).

In the current Hermes campaign, reviewing is local only. A checklist result does not authorize stage, commit, push, merge, deploy, provider calls or owner-only actions. Record exact checked paths and test results; mark anything unrun as unverified.
