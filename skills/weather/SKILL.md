# Weather Intel

> Live weather data from wttr.in — no API key required.

**Version:** 1.0.0
**Author:** Cabinet Core
**Agents:** friday, jarvis
**Requires:** httpx

Provides real-time weather and forecasts. Uses geolocation from query text.

## Usage
Agent prompts this skill when user asks about weather, temperature, rain, etc.

## Commands
- `weather <location>` — current conditions
- `forecast <location>` — 3-day forecast
