# Alpha Testing Invite Pack

Private recruiting assets for the pre-1.0 alpha loop. Use these for personal-network
outreach, not a broad public launch.

## Assets

- `jarvis-alpha-hook-vertical.mp4` - 22s vertical hook video for Facebook, LinkedIn,
  Stories/Reels, or direct messages.
- `jarvis-alpha-hook-thumbnail.png` - still frame for previews.
- `INVITE_MESSAGE.md` - paste-ready invite copy, caption, DM reply, and screening
  questions.
- `render_alpha_hook.py` - deterministic local renderer for the MP4 and thumbnail.

## Positioning

This pack is deliberately alpha-specific:

- asks for 2-3 serious testers, not mass signups;
- states the 2-4 week commitment;
- filters for Windows 11/Linux plus either an 8 GB VRAM GPU or an API key with billing;
- keeps the promise honest: local-first, governed, pre-1.0, owner-supported.
