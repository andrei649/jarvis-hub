## Why this is the first recovery slice

Hermes owns OpenAI SDK retry policy (`agent/auxiliary_client.py:181-196`), but Nerva's selected local path uses HTTPX, so copying an SDK rebuild helper would have no consumer. Hermes also refreshes/rotates provider credentials on auth/payment/rate errors (`:3697-3735,7576-7633`); Nerva video identities bind the exact credential and request into owner approval (`agents/core/llm/video_policy.py:40-54,205-250`), so changing the video key mid-execution needs a new signed approval contract. Its native video body sends no temperature/max_tokens/reasoning field to strip (`agents/core/video_analysis.py:336-340`). Hermes auto-discovery is limited when a main provider was explicitly selected, to avoid silently billing another account (`agent/auxiliary_client.py:4608-4674`). Nerva currently requires an explicit video/vision model or refuses (`agents/core/llm/model_roles.py:347-429`; `video_analysis.py:236-251`); automatic remote discovery would need provider capability proof, consent/cost selection and pre-approval binding. Those are separate requirements, not safe side effects of this parameter repair. The recommended slice advances one real H277 recovery behavior; H277 remains partial.
