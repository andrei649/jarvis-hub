### `signals/poll.ts` — the shared poller
`usePolled<T>(path, { admin, intervalMs = 30 000, enabled = true, demo, demoValue, parse, isEmpty, refreshOnFocus }) → Polled<T>` (a `Reading<T>` plus `refresh()`).

- One request per path (and admin flag) at the shortest interval any caller asked; each caller parses the shared raw answer with its own `parse` (keep `parse` and `isEmpty` at module level, stable) — a throwing `parse` makes that caller's reading `unknown`/`malformed`.
- Paused while the document is hidden; on return, readings re-render with their true age and due paths are asked at once.
- Outcomes: 401/403 → `refused` (`credential`, value null); no answer, 502, 504 → `offline` (`network`, last good value kept); 503 → `unknown` (`unavailable`); any other non-2xx → `unknown` (`http`, `status`); a 2xx whose body is not JSON (a proxy page) → `unknown` (`malformed`, last good value kept); a 2xx older than 2.5 intervals → `stale`; `isEmpty(value)` → `empty`; before the first answer → `unknown` (`checking`). `demo` and `enabled: false` never touch the network.
- `refreshPolled(path, {admin})` asks again now from anywhere (after a decision, "Verify again") and resolves when an answer asked for after the call has landed: a refresh during a request asks once more when that request ends and resolves only when that second answer lands (any number of such refreshes share the one follow-up). `pollSnapshot(path)` reads the shared state; `readingFromSnapshot` is the pure core; `resetPolling()` is for tests.
- It uses `apiGet`, so the existing credential behaviour (the loopback token prompt, the networked sign-in) is unchanged.

`navigate` is always `navigateHud` (a logical path from `pathOf`; never a `docketHref` / `decisionsHref`, which go through `openDocketEntry` / `openDecisionsCard`). `onFind(filter?: 'panels')` is `FrameProps.onFind` (opens the Ctrl K sheet; `'panels'` filters it to panels): every page that renders a `ContentsColumn` takes it and passes it on. `lang` is a `Lang`. `clock` is App's minute clock (a `Date` that changes once a minute; the 1-second clock moves into Cinema and Ambient). `turns` is App's `TabTurn[]`. `attention` comes from `useAttention()` (`signals/hooks`). Components call the shared hooks themselves (requests are shared, so a second caller costs nothing); props carry only what App owns.

**The verdict is computed in one place.** `useVerdict(hub, lang, {demo})` (E3, `signals/hooks.ts`) gathers every reading the §5.2 rules need — the hub snapshot, `useKillSwitch`, `useAuditVerify`, `useObserver`, `/api/health/components`, and memory and disk pressure through `usePressureReading()` (a `Reading<PressureReading>`, so "not answered" is not "no pressure") — and runs the pure `verdict()`. DayRegister, DayBand and Glance all call it, so Home and Glance cannot disagree; nobody passes App's legacy `PressureState` to a verdict (it starts at "none" and keeps the last state on failure). App's `usePressure` stays only for the notices' PressureBanner and its dismiss. (E2 may feed that banner from the same shared reading — its `PressureState` is built from the reading's `bootId` and `worst`; dismiss, then `refreshPolled('/api/system/pressure')` — so the path is polled once; until then it is asked twice a minute.)

- `model.ts` (`parseDocketFeed`, `parseDocketSummary`, `entryHolding`, `frictionOf`, `compareEntries`, `summaryOf`), `kinds.ts` (`kindSentence`, `kindWords`, `isMoney`, `runsOnlyInAuto`), `phrases.ts` (`phraseFor`, `phraseWord`), `special.ts` (`specialKindOf`, `SpecialKind` `image | consent | retention | voice | guardian`), `outcomes.ts` (`DecisionVerb`, `Outcome`, `DecisionRecord`, `outcomeOfDecision`, `outcomeOfEach`, `withRecord`, `placeRecords`, `RECORDS_KEPT` 200), `demo.ts` (`demoFeed`, `demoModel`, `demoSummary`, `demoPreview`), and the views `DocketEntryView`, `OutcomeLine`, `PayloadEditor`, `SignLine` / `SignControl`.

**`pages/`**
- `sources.ts`: the feeds the overview pages read, each `usePolled` with its own parser: `useRunningFeed`, `useSubagentsFeed`, `useJobsFeed`, `useBlockedFeed`, `usePaymentsFeed`, `useSkillChangesFeed`, `useRecordFeed` (`/api/security/audit/intent?limit=50`). `lanes.ts`: `buildTimeline`, `position`. `agent-states.ts`: `rosterAgents`. `common.tsx`: `PageLink`, `stamp`, `sinceWords`, `drawable`, `NoReading`. `RecordTable.tsx`, `Friction.tsx` (`TypedAction`, `TwoStepAction`). `testkit.ts` is for tests only.
