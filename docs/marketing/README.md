# docs/marketing — launch & teaser assets

Ready-to-use marketing material for the Jarvis Hub launch. All copy is grounded in verified repo
facts (re-checked 2026-06-10); all visual direction inherits from [`../BRAND_BOOK.md`](../BRAND_BOOK.md).

| File | What it's for | Hand it to |
|------|---------------|-----------|
| [`ANNOUNCEMENT.md`](ANNOUNCEMENT.md) | Launch blog post / Product Hunt / Show HN / press note — TL;DR → long form, with boilerplate | A writer, or paste directly |
| [`TEASER_PACK.md`](TEASER_PACK.md) | Taglines, ready-to-schedule social posts, a 60s video script, email + landing snippets, asset shot list | Social scheduler, video tool, email tool |
| [`DESIGN_BRIEF.md`](DESIGN_BRIEF.md) | Self-contained creative brief: exact palette/type specs, per-asset dimensions + layout, do/don't, approved proof points | **Claude Design**, Figma/Canva, a designer |

**Golden rules for anyone using these:**
1. **Numbers trace to the repo.** The approved proof points live in `DESIGN_BRIEF.md` §5; if a stat
   isn't there, check `BACKLOG.md` before putting it on an asset.
2. **Honesty is the marketing.** Never stage fake data for a screenshot — use real data or the
   clearly-badged demo mode. The product's whole pitch is that it doesn't lie; the marketing can't either.
3. **Restraint = trust.** Calm, premium, one idea per asset. Butler, not hype-man.
