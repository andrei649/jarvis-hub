## Deliberate boundaries

Replay only within a single live tool invocation; a fresh run starts without opaque state. Stateful transcripts cannot be compacted: overflow yields existing bounded context refusal, preserving state rather than silently dropping it. Completed plain answers are the only returned conversation material. No encrypted-state persistence or cross-conversation continuation, credential discovery, pricing/billing proof, live model availability or Codex OAuth claim. New protocol seams must not cause existing Gemini signature behavior or nonopaque providers to change.

## Official schema evidence and conservative limits

The HTML-embedded OpenAPI at https://docs.x.ai/developers/rest-api-reference/inference/responses was inspected locally (read-only artifact `/tmp/nerva-xai-official-responses.html`). Output message required fields are content/role/type; function required arguments/call_id/name/type; reasoning required summary/type. Item id/status are optional strings, not nullable: absence is preserved; explicit incomplete/in_progress/null statuses and malformed supplied IDs refuse. Four schema regression cases were RED then green. The native ciphertext projection uses the documented stateless encrypted item with summary=[]; optional plaintext reasoning content and summary text are validated then discarded, never displayed or retained in the envelope. This is a conservative schema-valid projection, not live acceptance evidence.

https://docs.x.ai/developers/models/grok-4.6 explicitly documents500000 context tokens; no4.5 window is inferred. The Responses request max_output_tokens schema is integer|null/int32, described as output plus reasoning tokens; it publishes no numeric per-model maximum.32768 is a conservative Nerva product ceiling (within the schema), not a claimed vendor maximum. The120s deadline and byte/item/call limits are likewise product bounds. No catalog probe or paid validation occurs.

Additional dialect boundary: `responses_dialect.input_items` refuses internal provider envelopes by default. The xAI policy opts in only AFTER verifying full history identity/projection; unchanged OpenAI paths cannot silently discard opaque state and send an incomplete transcript. Malformed native call name/arguments refuse before tool execution. RED3/6 native-boundary cases cover these gaps.

Scope remains nonpersistent: ToolTurn repr redacts envelopes, JSON serialization refuses the private object, context overflow/call truncation stops before tools. Lifetime is opt-in for xAI; wholly nonopaque late-child behavior remains unchanged. Completion rechecks after transport close prevent late usage publication. Static xAI error messages name xAI without response-body/credential text; OpenAI error strings stay exact.
