# CLI fish completion implementation plan

> Execute inline with superpowers:executing-plans and test-driven-development. Parent coordinates independent review.

**Goal:** Add `nerva completion fish` generated from the live argparse command tree, and refuse unsupported shell names in the public helper.

**Architecture:** Retain the existing bash/zsh generators and `command_tree` API. Add a fish generator that recursively walks argparse subparsers, emitting static completion candidates guarded by an exact command-word path predicate. Completion scripts contain no Nerva invocation, network calls or configuration writes. Use fish single-quote escaping for every generated command/path token.

**Tech stack:** Existing Python argparse, pytest, optional isolated fish runtime.

**Spec:** Frozen H004, “Get shell tab-completion for the command tree”, `docs/research/2026-09-07-hermes-absorption-ledger.json`: bash/zsh/fish scripts printed from the live argparse tree. No frozen requirement for option/value completion. This slice preserves existing bash/zsh behavior and implements command/subcommand completion, including nested future parser nodes, for fish. Options and arbitrary argument values remain outside the existing completion contract.

**Freshness:** Base `1ddd6c333a09e57a1c90462712bd7fc1477b65ef`; generated 2026-09-15. Branch `codex/backlog-cli-fish`. Current head will be the implementing commit. Next action: red tests, implementation, verification, parent review.

## Constraints

- Own only `agents/cli/nerva.py`, focused completion tests, this plan and a module guide.
- No global reports, dependencies, shell startup configuration, remote writes or policy changes.
- Completion derives candidates recursively from parser actions, never a second command list.
- Fish rendering quotes literal metadata; no candidate may execute shell syntax.
- Unsupported helper shell names raise ValueError; argparse advertises exactly bash, zsh and fish.
- Existing CLI online authority and transport paths remain unchanged.
- Rollback: revert the implementation commit. No persisted product data changes.
