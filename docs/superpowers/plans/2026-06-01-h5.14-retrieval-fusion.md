# H5.14 — Retrieval Fusion Engine

> **For agentic workers:** implement task-by-task, TDD. Steps use checkbox (`- [ ]`) syntax for tracking. Keep the suite green (`python -m pytest tests/ -q`, baseline **740 passed, 9 skipped**).

**Goal:** Fuse the two existing retrieval sources — the **vector store** (semantic similarity: Qdrant / `InMemoryVectorStore`) and the **knowledge graph** (factual relations: Neo4j / `InMemoryGraph`) — into one ranked result list using **Reciprocal Rank Fusion (RRF)**, so a single query blends conversational similarity with graph facts.

**Why RRF:** it is *rank*-based, not *score*-based, so it merges lists whose scores live on different scales (cosine similarity ∈ [-1,1] vs. graph relevance) **without normalization**:

```
rrf_score(d) = Σ_i  weight_i / (k + rank_i(d))
```

`rank_i(d)` is d's 1-based rank in list i (term omitted when d is absent from list i); `k` is a damping constant (default **60**, Cormack et al. 2009); `weight_i` biases a source.

**Architecture:**
- New `agents/core/memory/fusion.py`:
  - `FusedHit` dataclass — `{id, score, sources[], payload{}}`.
  - `reciprocal_rank_fusion(ranked_lists, *, k=60, weights=None, top_k=10)` — **pure, source-agnostic** (operates on `{source: [(doc_id, payload), …]}`); unit-tested offline.
  - `HybridRetriever(vector_store, graph, *, k, vector_weight, graph_weight)` — adapts the two stores' hit shapes to `(id, payload)` and calls the pure fuser. Injectable → testable with `InMemoryVectorStore` + `InMemoryGraph`, no Qdrant/Neo4j.
- Wire into `MemoryManager.hybrid_search(embedding=None, keyword=None, top_k=10)` (lazy-builds a `HybridRetriever` over `self.vectors` + `self.graph`).
- Settings: `memory.fusion_k` (60), `memory.fusion_vector_weight` (1.0), `memory.fusion_graph_weight` (1.0).

**Real hit shapes (verified):**
- `vector_store.search(embedding, k)` → `[{"id": str, "score": float, "metadata": dict}, …]`
- `graph.search(keyword)` → `[{"name": str, "type": str, "properties": dict}, …]`

**Tech stack:** Python 3.12, stdlib only (no new deps). Async-agnostic (the fuser is sync; `MemoryManager.hybrid_search` is async to match the manager's lock pattern).

```python
"""
fusion.py — Retrieval Fusion Engine (H5.14).

Blends ranked results from the vector store (semantic similarity) and the
knowledge graph (factual relations) into one ranked list via Reciprocal Rank
Fusion. The fuser is pure and source-agnostic so it is unit-tested offline.
"""
from __future__ import annotations

from dataclasses import dataclass, field
from typing import Optional


@dataclass
class FusedHit:
    id: str
    score: float = 0.0
    sources: list[str] = field(default_factory=list)
    payload: dict = field(default_factory=dict)


def reciprocal_rank_fusion(
    ranked_lists: dict[str, list[tuple[str, dict]]],
    *,
    k: int = 60,
    weights: Optional[dict[str, float]] = None,
    top_k: int = 10,
) -> list[FusedHit]:
    """Weighted Reciprocal Rank Fusion over already-ranked result lists.

    ranked_lists: {source_name: [(doc_id, payload), ...]}  (rank order = list order)
    """
    weights = weights or {}
    acc: dict[str, FusedHit] = {}
    for source, hits in ranked_lists.items():
        w = weights.get(source, 1.0)
        for rank, (doc_id, payload) in enumerate(hits, start=1):
            hit = acc.get(doc_id)
            if hit is None:
                hit = FusedHit(id=doc_id)
                acc[doc_id] = hit
            hit.score += w / (k + rank)
            if source not in hit.sources:
                hit.sources.append(source)
            for key, val in (payload or {}).items():
                hit.payload.setdefault(key, val)   # first non-empty wins
    return sorted(acc.values(), key=lambda h: h.score, reverse=True)[:top_k]
```

```python
class HybridRetriever:
    """Fuses vector-store + knowledge-graph retrieval into one ranked list.

    Stores are injected (duck-typed: `.search(...)`), so this is tested offline
    with InMemoryVectorStore + InMemoryGraph and works unchanged against
    Qdrant + Neo4j in production.
    """

    def __init__(self, vector_store=None, graph=None, *, k: int = 60,
                 vector_weight: float = 1.0, graph_weight: float = 1.0):
        self.vectors = vector_store
        self.graph = graph
        self.k = k
        self.weights = {"vector": vector_weight, "graph": graph_weight}

    def retrieve(self, *, embedding: Optional[list[float]] = None,
                 keyword: Optional[str] = None, top_k: int = 10) -> list[FusedHit]:
        ranked: dict[str, list[tuple[str, dict]]] = {}
        if embedding is not None and self.vectors is not None:
            vhits = self.vectors.search(embedding, k=top_k) or []
            ranked["vector"] = [(str(h.get("id")), h) for h in vhits if h.get("id")]
        if keyword and self.graph is not None:
            ghits = self.graph.search(keyword) or []
            ranked["graph"] = [(str(g.get("name")), g) for g in ghits if g.get("name")]
        return reciprocal_rank_fusion(ranked, k=self.k, weights=self.weights, top_k=top_k)
```

async def hybrid_search(self, embedding=None, keyword=None, top_k: int = 10):
    """Fuse vector similarity + knowledge-graph hits via RRF (H5.14)."""
    from .fusion import HybridRetriever
    async with self._lock:

            self.vectors, self.graph,
            k=getattr(self, "fusion_k", 60),
            vector_weight=getattr(self, "fusion_vector_weight", 1.0),
            graph_weight=getattr(self, "fusion_graph_weight", 1.0),
        )
        return retriever.retrieve(embedding=embedding, keyword=keyword, top_k=top_k)
