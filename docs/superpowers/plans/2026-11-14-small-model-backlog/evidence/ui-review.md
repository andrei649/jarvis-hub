## Confirmed behavior / claim gaps

1. **Pet backend picker and reference image do not deliver the labeled functionality.** Every selectable image backend (`procedural-pixel`, `svg-synth`, `local-vlm`) goes through the identical `_procedural_candidate` routine; the backend name only changes its hash seed. No image model is invoked. `_extract_reference_color` hashes raw file bytes and derives RGB from that hash rather than decoding/extracting image color. Consequently prompt semantics/remix instructions produce pseudorandom hash-derived shapes, and a reference image’s visible palette is not preserved; even same-colored images with different encodings can yield different tints. Present this as procedural sprite generation, not local-VLM generation or reference-image palette extraction. [generator](https://github.com/andrei649/jarvis-hub/blob/ffbfce81a2733f4b10dc2e60463b2931a51cdadf/agents/core/pets.py#L880), [hash color](https://github.com/andrei649/jarvis-hub/blob/ffbfce81a2733f4b10dc2e60463b2931a51cdadf/agents/core/pets.py#L349), [sprite algorithm](https://github.com/andrei649/jarvis-hub/blob/ffbfce81a2733f4b10dc2e60463b2931a51cdadf/agents/core/pets.py#L305).

2. **Benchmark prose incorrectly says synthesis starts as soon as quorum holds.** Production `_collect_drafts` awaits `asyncio.gather` over every proposer, so one slow proposer holds completion until its generation timeout even after enough drafts exist. `ensure_resident` is also outside `wait_for`, so the advertised per-proposer timeout does not bound model loading. This does not negate parallelism/failure tolerance, but removes the claimed early-quorum latency guarantee. [implementation](https://github.com/andrei649/jarvis-hub/blob/ffbfce81a2733f4b10dc2e60463b2931a51cdadf/agents/core/llm/moa.py#L486), [claim](https://github.com/andrei649/jarvis-hub/blob/ffbfce81a2733f4b10dc2e60463b2931a51cdadf/docs/benchmarks/nerva-vs-hermes-openclaw-2026-11-14.md).

## Benchmark interpretation

The harness does exercise Nerva production subsystems in-process with deterministic synthetic backends; its explicit `live_network_llm_calls = 0` disclosure is useful. It does not execute Hermes or OpenClaw. B1 compares against a hand-written fail-stop sequential chain; B2 deliberately sends sensitive prompts to an unguarded fake cloud backend; B3/B4 baseline failure rates are literal `0.0`; B5 sorts manifests in harness `_lww_order_manifests`, while production lot4 mailbox pull follows arrival order. These are invariant tests / synthetic pattern comparisons, not measured superiority over competitor products. The report discloses the B5 attribution, but its executive column “Hermes / OpenClaw Default” and “Why Nerva wins” exceed the experimental evidence.
