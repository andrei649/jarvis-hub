# Sunday Demo Script

## Title

Jarvis Signal Layer: from world events to personal relevance.

## 1. Open WorldView

Show:

- Provider: WorldMonitor
- Mode: Replay or Live
- Freshness: Good
- Signals analyzed
- Relevant signals
- Top risk level

Narrative:

> Jarvis now has a signal layer. WorldMonitor is the first external-world provider, but Jarvis owns the relevance, evidence, and action logic.

## 2. Ask: “What changed overnight that matters to me?”

Expected response:

- concise global brief;
- top relevant signals;
- why each matters;
- source/freshness note;
- confidence level.

## 3. Click a signal

Show source drawer:

- evidence source family;
- fetched/cached time;
- stale status;
- reliability;
- claim status.

Narrative:

> Jarvis does not just summarize. It can show what evidence supports each claim.

## 4. Country assessment

Open Romania or UAE assessment.

Expected:

- risk level;
- drivers;
- recommendations;
- evidence IDs.

## 5. Action queue

Show recommended actions:

- monitor airport or route;
- schedule next brief;
- add a watch target;
- no automatic execution.

Narrative:

> Jarvis recommends. The user approves.

## 6. Switch live/replay

Narrative:

> Replay mode makes this testable, demo-safe, and evaluable. Live mode uses WorldMonitor as the data plane.
